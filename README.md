# Data Center Heat Island | Replication Guide

**How to Measure a Data Centre's Heat Island Using Open Satellite Data**

A free, bilingual methodological guide by **Amenaza Roboto**, designed to help journalists, researchers, and civil society organizations investigate the thermal footprint of data centers using open satellite data.

## About the method

The guide explains how to distinguish the heat associated with changes in land cover from the additional heat generated by data center operations.

It provides a step-by-step workflow using Landsat satellite imagery, Google Earth Engine, R, comparable control buildings, and a difference-in-differences statistical model.

The method was developed for Amenaza Roboto's investigation *The Heat Behind the Cloud* and is intended for adaptation to other data centers, particularly those using outside-air cooling systems (free cooling).
